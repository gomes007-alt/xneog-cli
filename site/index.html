Same session, every surface.

The session is not a process in your terminal — it lives in xneog-agentd, a daemon with its own protocol: curated events, replay cursors, an approval queue, per-session transcripts. The terminal is one client. The xNeog iOS/macOS app is another. Detach anywhere, resume anywhere — nothing dies with the window.

Approvals are server-enforced. There is no --dangerously-skip flag to leak, because the daemon doesn't expose one.

Engines are adapters. Trust is policy.

One daemon, three engine classes today — each with the isolation it deserves.

Claude first-party

Persistent stream-json sessions on the official binary. Model & permission-mode switch mid-session with history preserved. Subagents and workflows render as live task cards with per-phase progress.

Grok jailed

Runs inside a macOS Seatbelt sandbox: the engine sees only its own workspace — your home directory is a wall of "permission denied". Turn-based spawns, prompt via file (never argv), resume across turns.

Claude API metered

A minimal agentic loop owned by the daemon itself — Messages API with Bash/Read/Write/Glob tools, same approval queue, central metering. Bring your key, or use an xNeog gateway key.

Sessions that survive

Every curated event persists to a per-session transcript. Restart the daemon, reconnect a client, replay from any cursor — history is never trapped in a process.

Import from Claude Code

xneog import <session-id> adopts an existing Claude Code session: history hydrated, resumable with full context. Migration is a ramp, not a cliff.

Permission profiles

safe asks for everything · edit lets file edits through, shell still asks · full doesn't exist — on purpose. The queue is the product.
